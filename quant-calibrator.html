Quant Pace Calibrator

Downloads ESPN play-by-play for recently finished Division I games, measures how scoring really unfolds minute by minute (especially the last 3 minutes), and tests that against straight-line pace on games it did not train on. Open it from your GitHub page on Wi-Fi and keep the screen on. Games are cached, so a second run is fast.
